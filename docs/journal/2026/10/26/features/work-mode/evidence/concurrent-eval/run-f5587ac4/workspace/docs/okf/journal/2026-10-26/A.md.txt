# Requests

A0+A1; verbatim requests are preserved under workspace `requests/`.

# Implementation

`mvcc_cache.py`. Cache uses a lock, per-key integer versions (including delete/eviction tombstones), staged atomic writes, and creation-time copied snapshot bindings. TTL is inclusive and transaction TTL starts at commit. Capacity is unlimited by default and evicts the oldest inserted live binding; overwrite/get do not refresh order. Transaction operations are applied in call order before eviction.
